## Mode bukti: `web_if_available`

Jika Anda memiliki alat pencarian/pengambilan web (mis. WebSearch/WebFetch), verifikasi **klaim empiris kunci** yang menentukan hasil dan catat di array `evidence` sebagai `{"claim": "...", "source": "<URL>", "note": "mendukung/melemahkan ..."}`. Prioritaskan sumber primer atau tinjauan sistematis. Jika alat web tidak tersedia, bekerjalah dengan pengetahuan internal dan jangan mengarang sumber. Isi `evidence_mode_used` dengan `"web"` atau `"internal"` sesuai yang benar-benar Anda lakukan.
